# Hotel Management System

A full-stack Hotel Management System developed as a client project to simplify and manage day-to-day hotel operations through a centralized platform.

## Features

- Customer registration and booking
- Room availability and room management
- Check-in and check-out management
- Receptionist dashboard and operations
- Housekeeping task and room status management
- Super Admin dashboard
- User and role management
- Online payment integration with Razorpay
- Booking and payment management
- Secure authentication and role-based access

## User Roles

### Customer
- Browse available rooms
- Make hotel bookings
- Manage booking details
- Make online payments

### Receptionist
- Manage customer bookings
- Handle check-in and check-out
- Manage room availability
- View and update booking information

### Housekeeper
- View assigned housekeeping tasks
- Update room cleaning status
- Manage room readiness

### Super Admin
- Manage users and roles
- Manage rooms and bookings
- Monitor hotel operations
- Manage overall system settings

## Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- Payment Gateway: Razorpay
- API: RESTful APIs

## Project Highlights

- Role-based access control
- Responsive and user-friendly interface
- Centralized hotel operations
- Secure online payment processing
- Real-time room and booking management
